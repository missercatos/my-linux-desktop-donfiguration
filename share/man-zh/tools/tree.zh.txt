tree - 树形目录结构显示

常用命令:
  tree                                        # 显示当前目录树
  tree -L 2                                   # 限制深度为2
  tree -d                                     # 只显示目录
  tree -I "node_modules"                      # 忽略指定目录
  tree -a                                     # 显示隐藏文件

关键选项:
  -L    限制深度
  -d    只显示目录
  -a    显示隐藏文件
  -I    忽略模式
  -f    显示完整路径
  --charset    字符集设置
