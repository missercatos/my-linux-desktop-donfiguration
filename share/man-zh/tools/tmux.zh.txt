tmux - 终端会话管理器

常用命令:
  tmux new -s session                        # 创建新会话
  tmux attach -t session                     # 连接到会话
  tmux ls                                    # 列出所有会话
  tmux kill-session -t session               # 关闭会话

快捷键（前缀键 Ctrl+b）:
  d    分离当前会话
  c    新建窗口
  n/p  切换到下一个/上一个窗口
  %    水平分割面板
  "    垂直分割面板
  方向键    切换面板

关键选项:
  new -s    新建指定名称会话
  attach -t    连接指定会话
  ls    列出会话
  kill-session    关闭会话
