docker - 应用容器引擎

常用命令:
  docker ps                                  # 列出运行中的容器
  docker images                              # 列出本地镜像
  docker run -it ubuntu bash                 # 运行容器并交互
  docker exec -it container bash             # 进入运行中的容器
  docker-compose up -d                       # 后台启动服务

关键选项:
  run -it    交互式运行
  exec -it    进入容器
  -d    后台运行
  -p    端口映射
  -v    挂载卷
  --name    指定名称
  compose    Docker Compose
