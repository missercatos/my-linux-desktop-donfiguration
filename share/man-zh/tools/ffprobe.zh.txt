ffprobe - 媒体文件信息查看

常用命令:
  ffprobe file.mp4                             # 显示基本信息
  ffprobe -show_format file.mp4                # 显示格式信息
  ffprobe -show_streams file.mp4               # 显示流信息
  ffprobe -v error -show_entries stream=width,height file.mp4  # 只显示尺寸

关键选项:
  -show_format    显示容器格式信息
  -show_streams    显示每个流的详细信息
  -v error    只显示错误信息
  -print_format json    JSON格式输出
  -show_entries    指定要显示的条目
