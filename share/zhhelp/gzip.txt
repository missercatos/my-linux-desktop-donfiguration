gzip  -  单文件压缩工具
用法: gzip [选项] 文件...
═══ 全部参数 ═══
常用参数:
  -d / gunzip    解压
  -k             保留原文件
  -1 ~ -9        压缩级别(默认6)
  -c             输出到标准输出
  -l             显示压缩比率
═══ 常用用法 ═══
常用指令集:
  gzip big.log                     # 压缩成 big.log.gz
  gunzip big.log.gz                # 解压
  gzip -k file                     # 压缩并保留原文件
  gzip -c file > file.gz           # 输出到指定名
  zcat file.gz                     # 不解压直接查看
  zgrep pattern file.gz            # 直接在压缩文件里搜
