cmake - 跨平台构建系统
═══ 全部参数 ═══
常用参数:
  -B 构建目录    指定构建目录
  -S 源码目录    指定源码目录
  --build 构建目录  执行构建
  -D 变量=值    设置变量
  -DCMAKE_BUILD_TYPE 类型  构建类型
  -DCMAKE_INSTALL_PREFIX 路径  安装路径
  --target 目标   构建特定目标
  --clean-first  清理后构建
  --parallel N   并行构建
  --verbose      详细输出
  -G 生成器     指定生成器
  -L             列出缓存变量
  --find-package 模式

═══ 常用用法 ═══
常用指令集:
  cmake -B build                   # 配置构建
  cmake --build build              # 构建项目
  cmake -B build -DCMAKE_BUILD_TYPE=Release  # Release构建
  cmake -B build -DCMAKE_INSTALL_PREFIX=/usr/local  # 设置安装路径
  cmake --build build --target clean  # 清理构建
  cmake --build build --parallel 4    # 并行构建
  cmake --build build -- -j8     # 指定并行数
