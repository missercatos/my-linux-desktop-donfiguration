zip  -  压缩成 zip 包
用法: zip [选项] 压缩包名 文件...
═══ 全部参数 ═══
常用参数:
  -r          递归压缩目录
  -9          最高压缩率(慢)
  -0          只打包不压缩
  -e          加密压缩(交互输入密码)
  -P 密码     指定密码压缩
  -u          仅更新新增/修改的文件
  -d          从压缩包删除文件
  -m          压缩后删除原文件
  -x 排除     排除匹配的文件
═══ 常用用法 ═══
常用指令集:
  zip -r backup.zip dir/                 # 压缩目录
  zip -9e secret.zip file1 file2         # 最高压缩+加密
  zip -r app.zip dir/ -x '*.log'         # 排除日志
  zip -d app.zip cache/                  # 包内删除
