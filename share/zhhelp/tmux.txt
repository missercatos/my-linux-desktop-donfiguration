tmux  -  终端复用器(会话/窗口/分屏)
前缀键: Ctrl+b (先按前缀再按其他键)
常用前缀快捷键:
  c / d        新建窗口 / 分离会话
  n / p        下一个/上一个窗口
  数字0-9      切到窗口N
  % / "        左右分屏 / 上下分屏
  方向键       切换分屏
  z            放大/还原当前分屏
  x            关闭当前分屏
  ?            快捷键列表
═══ 常用用法 ═══
常用指令集:
  tmux new -s work                 # 新建会话
  tmux attach -t work              # 重新连接
  tmux ls                          # 列出会话
  tmux kill-session -t work        # 结束会话
