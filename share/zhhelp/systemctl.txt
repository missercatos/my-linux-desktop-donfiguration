systemctl  -  systemd 服务管理
用法: systemctl 命令 [单元]
常用单元名: 服务名.service / 定时器.timer ...
═══ 常用用法 ═══
常用指令集:
  systemctl start/stop/restart 服务     # 启动/停止/重启
  systemctl enable --now 服务           # 开机自启并立即启动
  systemctl disable 服务                # 取消自启
  systemctl status 服务                 # 查看运行状态
  systemctl daemon-reload               # 重载配置
  systemctl list-units / --failed       # 列出单元/失败项
  systemctl is-active / is-enabled 服务 # 查询状态
  systemctl edit 服务                   # 写覆盖配置
  systemctl --user ...                  # 用户级服务
  journalctl -u 服务 -f                 # 看该服务日志
