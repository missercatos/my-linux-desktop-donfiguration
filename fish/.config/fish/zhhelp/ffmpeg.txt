ffmpeg  -  音视频处理瑞士军刀
用法: ffmpeg [全局选项] -i 输入 [选项] 输出
常用参数:
  -c:v copy      视频流直接复制(不重编码,快)
  -c:v libx264   重编码 H.264 (-crf 18-28 质量)
  -c:a copy / -c:a aac   音频处理
  -s 1280x720    分辨率
  -ss 时间       起始时间(00:01:30)
  -to 时间 / -t 时长   结束时间
  -vf 滤镜       (scale=..., fps=30...)
  -f 格式        强制输出格式
常用指令集:
  ffmpeg -i in.mp4 out.webm               # 转换容器
  ffmpeg -i in.mp4 -c:v copy out.mkv      # 快速改封装
  ffmpeg -i in.mp4 -ss 00:01:00 -t 10 -c copy cut.mp4  # 截取
  ffmpeg -i in.mkv -c:v libx264 -crf 22 -c:a aac out.mp4
  ffmpeg -i in.mp4 -vn out.mp3            # 提取音频
  ffmpeg -i in.mp4 -vf scale=720:-2 out.mp4  # 缩放
  ffmpeg -f concat -i list.txt -c copy out.mp4  # 拼接
