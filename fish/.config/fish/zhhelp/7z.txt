7z  -  7-Zip 压缩工具(支持多格式)
用法: 7z 命令 [选项] 压缩包 [文件...]
常用命令:
  a   添加/创建压缩包
  x   解压(保留目录结构)
  e   解压(全部平铺到当前目录)
  l   列出压缩包内容
  t   测试压缩包完整性
  d   从压缩包删除文件
常用参数:
  -r          递归
  -o目录      解压到指定目录(注意无空格)
  -p密码      设置/输入密码
  -mx=9       压缩等级 0-9
  -mfb=64     字典优化
  -t7z/-tzip  指定格式
常用指令集:
  7z a backup.7z dir/                   # 压缩
  7z a -mx=9 best.7z dir/               # 最高压缩
  7z x backup.7z -o/where/to            # 解压到目录
  7z l backup.7z                        # 查看内容
  7z a -p secret.7z file                # 加密
