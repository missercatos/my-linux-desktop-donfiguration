journalctl  -  systemd 日志查看
常用参数:
  -b / -b -1    本次/上次启动的日志
  -u 服务       只看某服务日志
  -f            实时跟踪(像 tail -f)
  -n 50         显示最后50条
  -p err        按级别过滤(emerg..debug)
  --since / --until  时间范围
  -k            内核日志
  -r            倒序(最新在前)
常用指令集:
  journalctl -f                    # 实时日志
  journalctl -u sshd.service -f    # 某服务实时日志
  journalctl -b -p err             # 本次启动的错误
  journalctl --since "1 hour ago"  # 近1小时
  sudo journalctl --vacuum-size=200M  # 清理日志
