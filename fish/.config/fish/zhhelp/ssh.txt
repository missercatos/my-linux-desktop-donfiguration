ssh  -  远程登录(加密)
用法: ssh [选项] 用户@主机
常用参数:
  -p 端口      指定端口
  -i 密钥文件   指定私钥
  -X / -Y      转发 X11 图形
  -L 本地端口:主机:端口  本地端口转发
  -R           远程端口转发
  -D 端口      动态转发(SOCKS代理)
  -C           压缩
  -v           详细调试(3个v更详细)
常用指令集:
  ssh user@host                     # 登录
  ssh -p 2222 user@host             # 非默认端口
  ssh -i ~/.ssh/id_ed25519 u@h      # 指定密钥
  ssh -L 8080:localhost:80 user@jump # 隧道
  ssh -D 1080 user@host             # SOCKS代理
