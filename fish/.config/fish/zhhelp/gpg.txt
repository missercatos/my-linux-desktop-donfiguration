gpg  -  GPG 加密/签名工具
常用指令集:
  gpg --full-generate-key       # 生成密钥对
  gpg --list-keys               # 列出公钥
  gpg --list-secret-keys        # 列出私钥
  gpg --export -a 邮件 > key.asc   # 导出公钥(ASCII)
  gpg --import key.asc          # 导入公钥
  gpg --encrypt -r 邮件 file    # 加密文件
  gpg --decrypt file.gpg        # 解密
  gpg --sign file               # 签名
  gpg --verify file.sig         # 验证签名
  gpg --delete-key 邮件         # 删除公钥
  gpg -c file                   # 对称加密(密码)
