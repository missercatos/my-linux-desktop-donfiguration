paru  -  AUR 包助手(用 Rust 写的 yay 替代)
用法: paru [操作] [包名...]
用法同 pacman/yay:
  -S / -Ss / -Syu / -Q / -Rns ...
额外:
  -G 包         查看 PKGBUILD
  --news        查看 Arch 新闻
  -c            清理缓存和孤儿
常用指令集:
  paru -Syu                       # 更新(含AUR)
  paru -S package                 # 安装
  paru -Ss kw                     # 搜索AUR
  paru -G pkg                     # 看PKGBUILD
