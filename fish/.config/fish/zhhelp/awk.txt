awk  -  文本处理编程语言
用法: awk [选项] '程序' 文件
基本结构: awk '{动作}' 文件, 按行分割字段($1,$2...)
常用内置: $NF 最后字段, NR 行号, NF 字段数, FS/-F 分隔符
常用指令集:
  awk '{print $1}' data.txt              # 打印第1列
  awk -F: '{print $1,$3}' /etc/passwd    # 冒号分隔
  awk '{sum+=$1} END{print sum}' f       # 求第1列总和
  awk '$3 > 100' f                       # 条件过滤
  awk 'NR>=2 && NR<=10' f                # 打2-10行
  awk '{print NR": "$0}' f               # 加行号输出
  ps aux | awk '$3>5'                    # CPU超5%的进程
