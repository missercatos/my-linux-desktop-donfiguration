npm  -  Node.js 包管理器
常用指令集:
  npm init -y                 # 初始化项目
  npm install 包名            # 安装依赖(生产)
  npm install -D 包名         # 安装开发依赖
  npm install -g 包名         # 全局安装
  npm uninstall 包名          # 卸载
  npm run 脚本名              # 运行scripts脚本
  npm start / npm test        # 启动/测试
  npm update                  # 更新依赖
  npm outdated                # 查看过期依赖
  npm list -g --depth=0       # 列出全局包
  npm audit                   # 安全检查
  npm publish                 # 发布包
