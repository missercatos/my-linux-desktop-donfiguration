chmod  -  修改文件权限
权限数字: r=4 w=2 x=1 (如 755 = rwxr-xr-x)
常用参数:
  -R          递归修改目录下所有
常用指令集:
  chmod +x script.sh              # 加执行权限
  chmod 644 file.txt              # 属主rw,其他r
  chmod 755 dir/                  # 可执行目录
  chmod -R 755 dir/               # 递归
  chmod u-w file                  # 去掉属主写权限
