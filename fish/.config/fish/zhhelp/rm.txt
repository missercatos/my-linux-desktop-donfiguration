rm  -  删除文件/目录(删除不可恢复!)
常用参数:
  -r          递归删除目录
  -f          强制(不询问/忽略不存在)
  -i          删除前询问
  -d          删除空目录
安全用法: 用 rm -I  或 alias rm='rm -I'
常用指令集:
  rm file.txt                       # 删文件
  rm -r dir/                        # 删目录
  rm -rf dir/                       # 强制删(慎用)
  rm -i *.log                       # 逐个确认
